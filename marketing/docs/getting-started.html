Getting Started

From zero to syncing in about five minutes.

Prerequisites

  • Claude Code installed and authenticated
  • A CrabTalk account (free)
  • At least two machines you want to keep in sync

Daemon download

CrabTalk ships a small Rust binary (crabtalk-daemon) that handles all P2P networking. It downloads automatically from GitHub Releases the first time you start the plugin — no Rust toolchain needed.

Installation

  1. Clone the repo

    Pick a permanent home — CrabTalk reads from this directory at startup.

    git clone https://github.com/ObtuseAglet/crabtalk ~/.claude/plugins/crabtalk

    Cloning into ~/.claude/plugins/ is optional but keeps things tidy.

  2. Register the plugin with Claude Code

    Tell Claude Code where to find the plugin:

    claude --plugin-dir ~/.claude/plugins/crabtalk

    Claude Code will pick up the .claude-plugin/plugin.json manifest and wire up the MCP server automatically.

  3. Authenticate

    Start a Claude Code session and run the setup command:

    /crabtalk:setup

    Claude will open claw.crabtalk.dev in your browser. Log in (or create an account), copy the token, and paste it back when prompted. Your device is now registered.

  4. Repeat on your other machines

    Clone the repo and run /crabtalk:setup on every machine you want to sync. Peers are discovered automatically — once two devices share the same account, they'll find each other and begin syncing.

Verifying sync is working

In any Claude Code session you can check the current state:

# Check daemon health and connected peers
/crabtalk:status

# Force an immediate sync push
/crabtalk:sync-now

The status output shows your device name, peer IDs of connected machines, and the timestamp of the last successful sync.

What happens on first sync

CrabTalk builds a manifest of all watched files on both machines, diffs them, and requests missing or newer files from the remote peer. Changes you made on machine A before machine B was set up are transferred in full — it's not a one-way overwrite.

Conflict handling

If the same file was modified on both machines while they were offline, CrabTalk keeps both versions and flags it as a conflict. Run /crabtalk:resolve-conflicts to review and pick a winner.

Uninstalling

Remove the --plugin-dir flag from your Claude Code launch config and delete the cloned repo. The daemon binary lives at ~/.claude/bin/crabtalk-daemon and can be removed manually.
