CrabTalk Docs

Everything you need to sync your Claude Code config across machines.

What is CrabTalk?

CrabTalk is a Claude Code plugin that keeps your configuration in sync across every machine you work on. Plugins, agents, settings, instructions — when you change something on one machine, it shows up everywhere else. No cloud storage. No manual exports. No configuration drift.

How it's different

Most sync tools route your files through a central server. CrabTalk uses libp2p to connect your machines directly, peer-to-peer. A lightweight rendezvous server helps peers find each other's addresses — after that, all data travels directly between your machines over an encrypted QUIC connection.

What gets synced

  • ~/.claude/plugins/ — installed plugins
  • ~/.claude/agents/ — custom agents
  • ~/.claude/settings.json — settings and statusline config
  • ~/.claude/CLAUDE.md — your global instructions
  • ~/.claude/keybindings.json — keyboard shortcuts

Where to start

Head to Getting Started to install the plugin and run your first sync. If you're curious about the internals, How It Works covers the full architecture. Stuck? Check Troubleshooting.

Plugin marketplace

CrabTalk is distributed as a Claude Code plugin. The daemon binary is downloaded automatically on first run — no Rust toolchain required.
